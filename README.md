# МРТ-ассистент

Решение кейса **«Здоровье под контролем ИИ: выявление и локализация опухолей
головного мозга с помощью искусственного интеллекта»** хакатона
**«Медицина 2050»**, трек «Студенты».

Веб-сервис анализирует МРТ-снимки головного мозга: определяет наличие и тип
опухоли (глиома, менингиома, опухоль гипофиза, опухоли нет) и подсвечивает
область её расположения прямо на снимке. Результат предназначен врачу как
вспомогательная информация и не является медицинским заключением.


## Возможности

- **Классификация** — ансамбль из 5 моделей ResNet34 (кросс-валидация по 5 фолдам),
  на выходе класс и вероятности по всем классам;
- **Локализация** — сегментация U-Net: предполагаемая область опухоли
  выделяется красной полупрозрачной маской поверх исходного снимка;
- **Понятный интерфейс** — загрузка PNG/JPG до 10 МБ, результат с уверенностью
  модели, таблицей вероятностей и выгрузкой CSV;
- **Работа на CPU** — не требует GPU, инференс одного снимка ~1 секунда.

## Быстрый старт

Требуется Python 3.12 (использовался при разработке и тестировании).

```bat
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

Сайт откроется на **http://127.0.0.1:5000**.

## Качество модели (кратко)

Кросс-валидация на отложенной тестовой выборке (222 снимка):

| Метрика | Диапазон по фолдам |
|---|---|
| Accuracy | 0.69–0.83 |
| F1-macro | 0.61–0.83 |
| AUC (макро, 4 класса) | 0.92–0.95 |
| AUC «опухоль / нет опухоли» | 0.99 |
| Чувствительность (опухоль) | 0.93–0.94 |
| Специфичность (опухоль) | 0.95–0.97 |

В продакшене используется усреднение вероятностей всех 5 фолдов (ансамбль).
Подробный разбор метрик, ошибок и ограничений — в [DOCUMENTATION.md](DOCUMENTATION.md).
