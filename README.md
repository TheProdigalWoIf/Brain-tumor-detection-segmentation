# Веб-сервис для анализа МРТ-cнимков

Данная модель представляет собой нейронную сеть, способную выявлять и определять локализацию опухолей
головного мозга с помощью многослойного перспетрона. Результат предназначен как
вспомогательная информация для врача и не является медицинским заключением.

Веб-сервис анализирует МРТ-снимки головного мозга : определяет наличие и тип
опухоли (глиома, менингиома, опухоль гипофиза, опухоли нет) и подсвечивает
область её расположения прямо на снимке. 

Формат считываемых изображений: gpg, tif, png размером до 10 мб
Инференс одного снимка ~1 секунда
Моодель целиком написана на Python 3.12 и сконструирована на основе библиотеки PyTorch с применением функций предобработки медецинских изборжений проекта MONAI core (ссылка на репозиторий проекта: https://github.com/Project-MONAI)

В качестве датасета для обучения был задействован набор из 12 064 МРТ-изображений головного мозга с контрастным усилением, разделённый на 4 класса (глиома, менингиома, опухоль гипофиза, отсутствие опухоли), предоставленный организаторами: https://disk.yandex.ru/d/SW2W69XsB2yubA

Для обучения классификатора была задействована модель ResNet34 с предобученными весами. Многоклассовый классификатор выдаёт как прогностический ответ (определённый класс), так и вероятностный (вероятности по всем пяти классам) для возможности оценки уверенности модели в прогнозе. 
Для обучеения сегментатора была задействована модель ResNet18 с предобученными весами.

На данном этапе программа всё ещё находится в разработке. Среди планируемых улучшений: 
- повышение точности сегментации
- дообучение на дополнительном датасете
- модернизация ансамблирования
- формирование моделью редактируемого текста с описанием результатов прогноза с указанием сомнений и ограничееий анализа
- возможность корректировки границ, определённях моделью сегментации, вручную


## Основные характеристики

- **Классификация** — ансамбль из 5 моделей свёрточной нейронной сети ResNet34, основанный на кросс-валидации по 5 фолдам. 
  на выходе модель предлагает прогноз класса и вероятности по всем классам;
- **Локализация** — сегментация на основе свёрточной нейронной сети типа U-Net: предполагаемая область опухоли
  выделяется красной полупрозрачной маской поверх исходного снимка;
- **Работа на CPU** — не требует GPU


## Установка и запуск модели

Требуется Python 3.12 (использовался при разработке и тестировании).

```bat
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

Сайт откроется на **http://127.0.0.1:5000**.

## Основные метрики

Кросс-валидация на отложенной тестовой выборке (222 снимка):

| Метрика | Диапазон по фолдам |
|---|---|
| Accuracy | 0.69–0.83 |
| F1-macro | 0.61–0.83 |
| AUC (макро, 4 класса) | 0.92–0.95 |
| AUC «опухоль / нет опухоли» | 0.99 |
| Чувствительность (опухоль) | 0.93–0.94 |
| Специфичность (опухоль) | 0.95–0.97 |

В продакшене используется усреднение вероятностей всех 5 фолдов (ансамбль).
Подробный разбор метрик, ошибок и ограничений — в [DOCUMENTATION.md](DOCUMENTATION.md).
